# 工业级章纲生成指南 (融合 Dramatica-Flow + Webnovel-Writer)

## 用途
用于根据大纲、前序章节小结、人物最新状态与世界观设定，生成一份具有严密戏剧节拍、因果链条与强追读力的单章章纲。

---

## 核心规划铁律（借鉴 Dramatica 戏剧理论与百万字长篇网文规范）

1. **核心冲突驱动 (Core Conflict)**：
   - 冲突必须源于“角色目标”与“外部/内部阻力”的剧烈碰撞，严禁无风起浪或靠机械巧合推动。
2. **节拍分段 (Beats Breakdown)**：
   - 每章严格拆解为 4-5 个具体节拍，标明每个节拍的剧情动作、情感状态与对话潜台词。
3. **POV 视角与信息边界 (Information Boundary)**：
   - 明确本章视角人物（POV），角色只能描写亲见、亲闻或合理推断的内容，绝不越界使用全知上帝视角抢先揭秘。
4. **追读力钩子设计 (Reading Power Taxonomy)**：
   - 明确本章末尾留下的钩子类型：
     - **危机钩 (Crisis)**：危险逼近 / 强敌登场 / 绝境倒计时
     - **悬念钩 (Mystery)**：反常细节 / 核心信息缺口 / 身份与线索交错
     - **渴望钩 (Desire)**：大奖可期 / 破境在即 / 关键宝物现世
     - **情绪钩 (Emotion)**：情感破冰 / 心动时刻 / 心疼与共鸣
     - **选择钩 (Choice)**：两难抉择 / 重大取舍 / 关键决策
5. **写前检查清单 (Pre-Write Checklist)**：
   - 登场人物、当前地理坐标、涉及法宝/道具、本章推进的伏笔编号、连续性与设定高危风险点。

---
